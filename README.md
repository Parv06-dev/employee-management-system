# Employee Management System

A full-stack Employee Management System built using **Spring Boot**, **Spring Data JPA**, **MySQL**, and **HTML/CSS/JavaScript**.
The application enables efficient employee record management and leave management through a responsive dashboard.

## 🚀 Features

- Employee Management (CRUD Operations)
- Leave Management
- Dashboard with employee and leave statistics
- RESTful APIs using Spring Boot
- MySQL database integration
- Responsive frontend
- Frontend and backend integration

## ⚙️ Getting Started

### Clone Repository

```bash
git clone https://github.com/Parv06-dev/employee-management-system.git
```

### Backend

```bash
cd employee-management-system

mvn spring-boot:run
```

### Frontend

```bash
cd frontend

node server.js
```

Open:

```
http://localhost:3000
```
